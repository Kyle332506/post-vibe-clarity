# PostVibeClarity v0.1.0 — Stable foundation

## Foundation

v0.1.0 is the stable foundation release of PostVibeClarity. It provides a read-only, evidence-backed starting point for preparing vibe-coded projects for production. The [foundation coverage map](../foundation-coverage.md) is the source of truth for what this release implements and where its boundaries remain.

## Included checks

- Node and static-project discovery for documented web, mobile, library, CLI, framework, and likely account-email signals.
- Catalog routing for valid `readiness.yaml` sidecars, including explicit `unverified` results when a routed implementation is unavailable.
- Redacted secret-exposure inspection for supported source and configuration formats.
- Privacy-notice candidate inspection when likely account-related personal-data collection is detected.
- Markdown and JSON reports that retain evidence, findings, and unverified areas without an overall readiness score.

For the precise automated behavior and explicit boundaries of each check, read the [foundation coverage map](../foundation-coverage.md).

## Known limitations

This release does not provide a remediation engine, complete nine-domain audit catalog, deep artifact packs, framework or provider adapters, deployed-environment verification, or cross-agent runtime acceptance. A report records the evidence and checks available to it; it is not a production-readiness, security, compliance, or defect-free guarantee.

## Compatibility evidence

The supported installation and invocation details are tracked in the [compatibility evidence](../installation/compatibility.yaml). Current labels distinguish documented guidance from tested runtime behavior; no blanket cross-agent runtime support claim is made.

## Verification

Before publishing or depending on this release, run the documented foundation gate from a clean checkout:

```bash
pnpm install --frozen-lockfile
pnpm verify:foundation
```

Review the generated evidence and any `unverified` areas before making a launch decision. Security reports follow the private process in [SECURITY.md](../../SECURITY.md).

## Disclaimer

PostVibeClarity supports production preparation, but it does not guarantee that a project is production-ready. It cannot find every vulnerability or prove that security is fully hardened. Read the complete [disclaimer](../../DISCLAIMER.md) before relying on a report.
